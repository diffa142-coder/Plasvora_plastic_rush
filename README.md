# Plasvora: Plastic Rush

Game 3D Endless Runner bertema pengelolaan sampah plastik untuk pameran dan perlombaan aplikasi **Plasvora**.

## Fitur Utama
- **Adegan Pembuka & Pengejaran:** Mengejar karakter pembuang sampah sembarangan yang juga melemparkan rintangan plastik ke lintasan.
- **Mekanik Tendang Sampah ke Tong:** Menendang sampah kresek agar melambung masuk ke dalam tong sampah kotak berstiker **PLASVORA**.
- **Rintangan Sampah Plastik:** Botol plastik PET, tumpukan karung/kresek plastik, serta jerigen dan gelas plastik.
- **Kontrol Mobile & Desktop:** Mendukung *touch swipe* (HP/Tablet) maupun keyboard/mouse di PC.
- **Mode Pameran:** Papan rekor lokal (Top 5 pengunjung) dan fakta edukasi daur ulang di layar *Game Over*.

## Menjalankan Proyek
```bash
npm install
npm run dev
```

## Build Produksi
```bash
npm run build
```
Hasil build akan tersimpan di folder `dist/`.
